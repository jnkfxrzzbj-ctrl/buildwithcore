Current Performance specification · CORE editorial assessment

Specification: RECOMMENDED

Reviewed 25 Oct 2026

Who it is for. A DIY builder seeking high-quality 1440p gaming, exact component choice and an AM5 upgrade path.

Our balanced specification: the six-core 9600X supports a capable 16GB graphics card, with 32GB memory, a specified modular power supply and straightforward air cooling. This recommendation values the build experience and component quality alongside frame rate.

Why these parts, and what to consider

Strengths

  • RX 9070 XT targets demanding 1440p gaming; 4K is an option with game-appropriate settings.
  • AM5, 32GB DDR5 and an RM850x provide a useful foundation for later upgrades.
  • Low-profile memory and the Freezer 36 keep the cooling plan simple.

Trade-offs

  • 1TB can fill quickly with large games. Ray-tracing performance varies substantially by title.
  • The observed memory price is a weakness; CL28 is not essential and does not alone justify a premium.
  • This is not a cheapest-PC claim: the earlier comparable prebuilt included Windows, assembly and system support at a lower component comparison price.

Quality-focused DIY tier. Pay for exact parts and building it yourself, not an assurance of savings over a prebuilt.

Dated cost reference: £1,864.85 on 25 Oct 2026. VAT-inclusive component observations from the 25 October 2026 owner review. Excludes delivery, Windows, peripherals, assembly and whole-system support. Not a current quote, buying threshold or guaranteed total.

Independent component testing supports the intended use; these are not measured CORE system results.

HOLD — buying criteria awaiting approval. CORE is not currently recommending purchase of this complete build.

  • Processor: AMD Ryzen 5 9600X
    Exact model & compatibility

    100-100001405WOF

    Use stock power settings. MSI lists Ryzen 5 9600X support from BIOS 7E81v1A0. Confirm the supplied BIOS; use only this exact motherboard support page and its Flash BIOS instructions if an update is needed. No cooler is included with the CPU.

  • Graphics: PowerColor Reaper Radeon RX 9070 XT 16GB
    Exact model & compatibility

    RX9070XT 16G-A

    289mm body / 304mm including bracket; fits the H6 Flow 365mm length allowance. Install in PCI_E2. Use two separate supplied RM850x PCIe 6+2-pin leads, one per socket. Do not use EPS cables or the unused 12V-2x6 lead.

  • Motherboard: MSI B850M GAMING PLUS WIFI6E
    Exact model & compatibility

    B850M GAMING PLUS WIFI6E

    MSI B850M GAMING PLUS WIFI6E, micro-ATX. Fit only matching standoffs. RAM in A2/B2, SSD in M2_1, GPU in PCI_E2 (the long CPU-connected slot, not PCI_E1). CPU support starts at 7E81v1A0 for both 9600X and 9800X3D. Connect 24-pin ATX and the CPU EPS leads to the labelled power headers; JFP1 for case switches, JAUD1 for audio and matching USB headers per manual.

  • Memory: KLEVV FIT V black 32GB (2×16GB) DDR5-6000 CL28
    Exact model & compatibility

    KD5AGU880-60B280L

    Install both 33.21mm-high modules in A2/B2. Start at JEDEC defaults; allow memory training. EXPO 6000 is optional overclocking, not a guaranteed speed. If unstable, return to defaults. Exact QVL membership is not claimed.

  • Storage: WD Black SN7100 1TB
    Exact model & compatibility

    WDS100T4X0E-00CJA0

    Bare M.2 2280 PCIe 4.0 NVMe drive. Install in M2_1, secure the retention and remove the board heatsink thermal-pad film before refitting it.

  • Power: Corsair RM850x (2024) ATX 3.1 — UK
    Exact model & compatibility

    CP-9020270-UK

    160mm PSU within the H6 Flow 200mm allowance. Use two separate supplied Type 4 PCIe 6+2-pin cables for the Reaper GPU. CPU/EPS cables go only to motherboard CPU power. Never reuse another PSU’s modular cables. Leave the native 12V-2x6 GPU cable unused.

  • Cooling: Arctic Freezer 36 — standard silver fins / black fans
    Exact model & compatibility

    ACFRE00121A

    159mm tall against the H6 Flow 163mm limit. Use the supplied AM5 mounting kit and paste; retain the AM5 backplate. Remove the cold-plate protective film. Connect the two PWM fans via their PST connection to CPU_FAN1. Follow the Arctic manual for mounting orientation and tightening.

  • Case: NZXT H6 Flow black — original non-RGB
    Exact model & compatibility

    CC-H61FB-01

    Original non-RGB CC-H61FB-01: GPU allowance 365mm, cooler 163mm, PSU 200mm. Use micro-ATX standoffs only. Connect the three included intake fans to suitable SYS_FAN headers within their current ratings; set DC/PWM mode for the actual plugs. Route JFP1, JAUD1 and USB leads using the board manual. Check cable bends and panel closure before powering on.
