Exact hardware checklist

Match these eight models to the parts you receive. Product references help identify hardware; they are not live buying recommendations. Keep the exact manufacturer manuals beside you.

  1. AMD Ryzen 7 9800X3D

    100-100001084WOF

    Ryzen 7 9800X3D, AM5, no included cooler. MSI lists support from BIOS 7E81v1A0 on this exact board. Confirm the supplied BIOS and follow its Flash BIOS instructions if needed. Keep stock power settings; do not apply automatic motherboard overclocking.

    Exact product reference ↗

  2. PowerColor Reaper RX 9070 XT 16GB

    RX9070XT 16G-A

    289mm body / 304mm including bracket; fits the H6 Flow 365mm length allowance. Install in PCI_E2. Use two separate supplied RM850x PCIe 6+2-pin leads, one per socket. Do not use EPS cables or the unused 12V-2x6 lead.

    Exact product reference ↗

  3. MSI B850M GAMING PLUS WIFI6E

    B850M GAMING PLUS WIFI6E

    MSI B850M GAMING PLUS WIFI6E, micro-ATX. Fit only matching standoffs. RAM in A2/B2, SSD in M2_1, GPU in PCI_E2 (the long CPU-connected slot, not PCI_E1). CPU support starts at 7E81v1A0 for both 9600X and 9800X3D. Connect 24-pin ATX and the CPU EPS leads to the labelled power headers; JFP1 for case switches, JAUD1 for audio and matching USB headers per manual.

    Exact product reference ↗

  4. Klevv FIT V 32GB (2×16GB) DDR5-6000 CL28

    KD5AGU880-60B280L

    Install both 33.21mm-high modules in A2/B2. Start at JEDEC defaults; allow memory training. EXPO 6000 is optional overclocking, not a guaranteed speed. If unstable, return to defaults. Exact QVL membership is not claimed.

    Exact product reference ↗

  5. WD Blue SN5100 2TB

    WDS200T5B0E-00CPE0

    Bare 2TB M.2 2280 SN5100 in M2_1. Secure the retention and remove the heatsink thermal-pad film. The extra capacity is for a larger game library; it is not a promise of higher frame rates.

    Exact product reference ↗

  6. Corsair RM850x (2024), UK

    CP-9020270-UK

    160mm PSU within the H6 Flow 200mm allowance. Use two separate supplied Type 4 PCIe 6+2-pin cables for the Reaper GPU. CPU/EPS cables go only to motherboard CPU power. Never reuse another PSU’s modular cables. Leave the native 12V-2x6 GPU cable unused.

    Exact product reference ↗

  7. Thermalright Peerless Assassin 120 SE non-RGB

    PA120 SE 1700

    Peerless Assassin 120 SE non-RGB, not another revision. Use its AM5 kit and retain the AM5 backplate. Remove cold-plate film and apply paste according to the manual. Two PWM fans connect to CPU_FAN1 with the supplied splitter within the header rating. Nominal height 155mm versus the case’s 163mm: check the front fan clears 33.21mm RAM without exceeding 163mm. Exact fan position and stock-load temperatures require physical verification.

    Exact product reference ↗

  8. NZXT H6 Flow black (2023)

    CC-H61FB-01

    Original non-RGB CC-H61FB-01: GPU allowance 365mm, cooler 163mm, PSU 200mm. Use micro-ATX standoffs only. Connect the three included intake fans to suitable SYS_FAN headers within their current ratings; set DC/PWM mode for the actual plugs. Route JFP1, JAUD1 and USB leads using the board manual. Check cable bends and panel closure before powering on.

    Exact product reference ↗

Assembly, first boot and care

Follow the assembly checklist, then install Windows. Check CPU temperature and fan operation at first boot, then check temperatures and stability under load before enabling memory profiles. Stop if cooling is not working; inspect mounting and cabling with the power disconnected.
