Processor (CPU)

AMD Ryzen 5 5600 boxed

100-100000927BOX

Boxed AM4 processor includes Wraith Stealth. MSI lists the Ryzen 5 5600 from BIOS 7C95v2A. Ask the seller to confirm the shipped BIOS; if needed, follow the exact board’s Flash BIOS Button instructions. This CPU has no integrated graphics: plug the monitor into the graphics card.

02
Graphics card (GPU)

Palit GeForce RTX 5060 Dual 8GB (non-OC)

NE75060019P1-GB2063D

1080p-focused 8GB card. Reduce texture quality in games that exceed its memory; do not assume maximum settings. Fit in PCI_E1 and connect one PSU PCIe 6+2-pin plug. The card uses eight PCIe lanes and runs at PCIe 4.0 on this platform. Palit specifies 262.1 × 126.3 × 40.1mm, below the 365mm case length limit, and a 550W recommended PSU; this build uses 650W.

03
Motherboard

MSI B550M PRO-VDH WIFI

B550M PRO-VDH WIFI

Exact B550M PRO-VDH WIFI, not the CEC variant. Install RAM in DIMMA2/DIMMB2 and the SSD in M2_1. Match micro-ATX standoffs. Connect 24-pin ATX and CPU_PWR1 using the CPU/EPS cable, JFP1 for case switches, JAUD1 for audio and the matching USB headers. Use the board manual for pin positions.

Two 8GB DDR4 modules in A2/B2. Start at default memory settings, then try A-XMP 3200 only after a stable first boot. This DDR4 kit cannot be reused on an AM5 DDR5 board.

Corsair CX650 (2023), UK

CP-9020278-UK

650W non-modular power supply, 125mm long within the case’s 200mm allowance. Use its fixed CPU/EPS cable for CPU_PWR1 and one PCIe 6+2 plug for the GPU. Tie unused leads away from fans. Never open the PSU.

CPU cooler

AMD Wraith Stealth bundled with boxed CPU

Included with 100-100000927BOX

Included with the boxed CPU; do not buy a second cooler. Remove the AM4 plastic retention brackets but retain the backplate. Follow AMD’s screw-mounted cooler instructions and tighten evenly. Use the pre-applied paste once; do not add more on top. Connect its fan to CPU_FAN1.

Case

NZXT H6 Flow black (2023)

CC-H61FB-01

Original black non-RGB CC-H61FB-01 with three intake fans. GPU allowance 365mm and cooler 163mm. Connect included fans to SYS_FAN headers within the board ratings; choose DC/PWM mode for their actual plugs. Check front USB and audio connections against the exact board manual. No fan hub or extra fan is assumed.
