BEFORE YOU PICK UP THE SCREWDRIVER

QUESTIONS.
ANSWERED CLEARLY.

The things first-time builders actually worry about: compatibility, Windows, tools, changing parts and what to do when the first power button press doesn't go exactly to plan.

01Do I need to know anything about PCs before I start?+

No. CORE is designed around first-time builders. You do need to be comfortable following instructions carefully, checking part orientation before applying force, and using the motherboard manual alongside the guide when a connector label differs.

02Are the three builds guaranteed to be compatible?+

The builds are selected as complete systems rather than independent shopping lists. Compatibility is part of the recommendation. Product revisions can happen, though, so the exact model names on the build page matter more than buying something that merely looks similar.

03Why doesn't the Starter build use the newest platform?+

Because a CORE should maximise what you notice, not what looks newest on a specification sheet. A mature AM4 platform can free meaningful budget for the graphics card. At the Starter tier, that trade can produce a better gaming machine.

04Why do you recommend AMD graphics cards?+

At the prices used for the current builds, AMD cards provide strong conventional gaming performance and 16GB of graphics memory. Nvidia may still be preferable for someone who prioritises specific CUDA workloads, certain creator applications or Nvidia-exclusive features; CORE is optimising these machines primarily for gaming value.

05What happens if a component price suddenly rises?+

Don't blindly buy it. Each build page uses a rough 'good price' target rather than pretending prices are fixed. The principle is simple: we recommend the part, not overpaying for it.

06Do I need to buy Windows?+

You need an operating system if you want to use the PC normally. Exact assembly and first-boot guides are being prepared and are not yet released. Licensing is separate from the hardware build.

07What tools do I need?+

A good Phillips #2 screwdriver covers most of the job. A small container for screws is useful, and cable ties or reusable hook-and-loop straps help with cable management. You do not need a specialist PC tool kit.

08What if the PC does not turn on first time?+

Do not panic and do not start dismantling everything at once. Check the PSU switch, 24-pin motherboard power, CPU/EPS power, front-panel power-switch pins, graphics-card power and monitor connection first. Re-seating memory is also a common fix for a new system that powers on but does not POST.

09Can I swap one recommended part for another?+

Sometimes, but that is where compatibility work starts again. A different graphics card may be longer, a different cooler may need different mounting hardware, and another motherboard may move headers or change BIOS requirements. If you deviate, check socket, memory type, case clearance, PSU capacity and connectors.
