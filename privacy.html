Privacy & Cookies

A straightforward site.

What this site does

CORE is a static information website. We do not provide accounts, contact forms, email sign-ups or price alerts in this release. CORE does not use analytics, advertising pixels or tracking scripts, and does not set cookies or use browser local storage to track visitors.

Hosting

This site is prepared for hosting on GitHub Pages. When served by GitHub Pages, GitHub logs and stores visitors’ IP addresses for security purposes, including visits made without a GitHub account. GitHub describes its handling of personal data in its own privacy statement.

Links and build choices

Retailer and product-source links take you to other websites, whose privacy and cookie policies apply there. We do not embed their content or send them information until you follow a link. A Performance guide link can contain the chosen hardware combination so the matching notes can be shown. This is not an account or personal identifier; CORE does not save a personal purchase history.

Questions and changes

Our contact details are being set up; see the Contact page. No enquiry form or email collection is implemented here. We will update this notice if the site’s features or data practices change. Last updated: 26 September 2026.
